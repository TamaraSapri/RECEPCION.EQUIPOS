Recepción y entrega de Equipos | SAPRI
GitHub Pages

1. Completa primero la instalación del ZIP de Supabase.
2. Abre config.js con un editor de texto. Reemplaza PEGA_AQUI_LA_PROJECT_URL y PEGA_AQUI_LA_PUBLISHABLE_KEY con los dos valores de Connect en tu proyecto. Conserva las comillas. En este archivo solo se usa la clave pública.
3. En el repositorio de GitHub para esta app, selecciona Add file → Upload files. Sube el contenido descomprimido de este ZIP, incluidas las carpetas lector y src. index.html, config.js, app.js y estilos.css deben quedar en la raíz. Guarda con Commit changes. El ZIP de Supabase y sus fichas son para uso administrativo.
4. Abre Settings → Pages → Source → Deploy from a branch. Selecciona main (o la rama donde subiste los archivos), /(root) y Save. Abre la URL que muestre GitHub Pages cuando termine la publicación.
5. Entra con una cuenta @sapri.cl confirmada y su contraseña en Supabase.

La app viene compilada. Las rutas son relativas para funcionar también bajo /nombre-del-repositorio/. Para modificar el código posteriormente, edita src, ejecuta npm install y npm run build y sube el app.js actualizado junto con el código fuente.
